# profile_maker

メンバー情報（名前・フリガナ・年齢・地域・職業・家族構成・ニーズ・性格・やる理由・その他・登録日・紹介者（年齢・地域・職業）・グループ・つなぎ・PBS）と写真（メンバー／紹介者）を入力し、プレビューで確認してから PNG 画像（幅 1080px、高さは入力量に合わせて自動）としてダウンロードできる 1 画面完結のツールです。

- `index.html` をブラウザで開くだけで使えます（インストール不要）
- 入力内容・写真はブラウザ内だけで処理し、保存や送信はしません
- テンプレート（ベーシック / ソフト / ダーク）とテーマカラーを選べます（文字はゴシック体）
- 写真はトリミング画面で切り抜き範囲（移動・大きさ変更）と 90° 回転を自由に調整できます
